## Apa itu QuizBot ?
QuizBot adalah sebuah bot discord yang bisa membuat, menambahkan, mengedit, dan menghapus quiz!
Bot ini bisa membantumu jika kamu ingin belajar sambil bermain bersama teman - teman !

## alat yang digunakan :
vscode
discord.py
sqlite3

## Perintah yang bisa digunakan :
1. /quiz -> Mulai quiz
2. /add_question_modal -> Tambah soal dengan popup (pilih kategori: Matematika, Geografi,Umum)
3. /leaderboard -> Lihat papan peringkat
4. /score -> Lihat score kamu
5. /edit_question -> Edit soal dengan popup (Hanya bisa edit soal yang kamu buat)
6. /delete_question -> Hapus soal dengan popup 
7. /admin_review_edit -> Review request edit soal (Admin)
8. /admin_review_delete -> Review request hapus soal (Admin)
9. /admin_review -> Review request tambah soal (Admin)
